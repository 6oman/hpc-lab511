# Практическая работа 5.11 «Подпроцессы»

Дисциплина «Высокопроизводительные вычисления», Московский Политех.
Исполнитель: Андреев А.В., группа 241-363.

В репозитории лежат программы и результаты замеров из отчёта.

## Файлы

| Файл | Что делает |
|---|---|
| `lab511_part1.py` | Пример из задания: конвейер из двух подпроцессов `ls -l \| grep pip` и аналог на чистом Python. Сравнение времени. |
| `lab511_ipython.ipy` | Тот же конвейер из задания для IPython (`%timeit`). |
| `lab511_part2.py` | Собственный пример: сжатие 16 файлов gzip четырьмя способами (по очереди, подпроцессы по одному, параллельные подпроцессы, потоки). |
| `timings_darwin.csv` | Сырые замеры `lab511_part2.py` на macOS (30 повторов). |
| `figs/` | Диаграммы VizTracer. |

## Как запустить

```
python3 lab511_part1.py        # быстрый показ, около 3 секунд
python3 lab511_part1.py 300    # полная статистика (300 повторов)
python3 lab511_part2.py        # быстрый показ
python3 lab511_part2.py 30     # полная статистика (30 повторов)
ipython lab511_ipython.ipy     # пример из задания в IPython
```

Нужен Python 3 и команды `ls`, `grep`, `gzip` (macOS и Linux).
